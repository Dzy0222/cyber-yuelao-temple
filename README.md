# 赛博月老庙 Cyber Yue Lao Temple

一个手机优先的古风像素风互动网站原型。9项需求中：

1. 响应式像素风首页 ✅ 使用附带的原创生成场景图片
2. 进入庙宇场景切换 ✅
3. 点香与摇签动画 ✅
4. 四类心愿和30支原创签文 ✅
5. Canvas 生成和保存 PNG ✅
6. 手机浏览器适配 ✅（需要真机回归测试）
7. 原创程序合成背景音乐与静音开关 ✅（需要点击开启）
8. 真实用户心愿墙 🟡 接口与审核数据库 SQL 已提供，需要自己配置 Supabase 才能联网；无配置是清楚标注的本机演示模式
9. 3D 场景和人物移动 ✅ 使用 Three.js 实时生成低多边形3D古风庭院，WASD/方向键和触屏控制；需要互联网加载 Three.js 模块

## 本地运行

该项目使用原生 ES modules，请从目录启动 HTTP 服务，而不是双击 index.html：

```bash
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080`。

## 正式上线

整个 `cyber-yuelao` 文件夹可作为静态站点上传到 Netlify、Cloudflare Pages 或 Vercel。构建命令留空，发布目录设为根目录。也可用 GitHub 仓库连接托管服务。

**重要：** 三维场景引用 `https://esm.sh/three@0.170.0`，需要能访问该 CDN 的网络环境；CDN 被屏蔽时自动回退到像素背景。正式运营建议将依赖自托管。

## 联网心愿墙（可选）

1. 在 Supabase 创建新项目。
2. 在 SQL Editor 运行 `docs/supabase.sql`。
3. 到项目设置中找到 Project URL 与 **publishable/anon** 公钥，放入 `config.js` 的两个字符串。**禁止放 service_role、secret key 等高权限凭据。**
4. 部署后匿名用户可提交心愿，但新心愿默认 `approved=false`；管理者在 Supabase 仪表板人工审核后修改 `approved=true`，才会出现在公共墙上。
5. 正式开放前务必添加 CAPTCHA、防刷/限流、投诉或内容删除通道、隐私告知与适当的审核流程。浏览器上的简单手机号检测不能代替真正的内容安全审核。

没有设置 URL/anon 公钥时，页面会显示「本机演示 · 不公开」，本地愿望存在该浏览器的 localStorage，其他用户看不到。

## 技术与局限

- 无账号、无个人身份信息收集，签文娱乐性质，不作真实预测。
- 默认音频为原生 Web Audio 合成的简单环境旋律，不使用现成版权音乐。
- 三维美术是程序性低多边形场景，不是首页图片里的逐像素可行走环境；两者视觉还可以进一步统一。
- 首页素材来自本次制作的图片；请勿移除其文件。
- 手机端 PNG 下载行为因浏览器而异，可能会下载到「文件」而非「照片」。
- 正式上线需补足跨设备测试、无障碍审查、心愿墙反滥用、隐私条款与稳定性测试。
